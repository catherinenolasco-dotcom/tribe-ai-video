# Cat Nolasco x Tribe AI

Supporting pages for my Senior People Operations Manager application at Tribe AI. Each page is a single self-contained HTML file styled after tribe.ai. All people, tickets and numbers are synthetic sample data.

| Page | What it is |
| --- | --- |
| `reel.html` | The ~1 minute screen-share reel I narrate in my Loom. Press H to hide the buttons, Space to start. |
| `employee-change-agent.html` | Demo of the Employee Change Agent: routes an employee change for approval with a before and after view. |
| `peoplepal-askpeople.html` | Interactive PeoplePal phone app prototype and the AskPeople board with ticket types, SLAs and automations. |
| `cat-x-tribe.html` | My work laid out against the employee lifecycle: hire, change, leave, exit. |
| `jd-match.html` | The job description mapped to my experience. |
| `companies.html` | Companies I have partnered with. |

## View it
Open `index.html` in a browser, or enable GitHub Pages on the main branch to host it.
